# 第九十章 四十年

沈月棠和顾清歌在一起四十年了。

四十年。一万四千六百个日夜。

她们从三十岁走到了七十岁。从黑发走到了白发。从年轻走到了年老。

但她们的爱没有变。

"月棠，四十年了。"

"嗯。"

"你还记得我们第一次见面吗？"

"记得。你站在门口，穿着白色的裙子。月光洒在你身上。我以为我看到了月亮。"

"月棠，你那时候好严肃。我有点怕你。"

"怕我？"

"嗯。你看起来像一座冰山。但后来我发现，冰山下面藏着最温柔的心。"

"清歌，你那时候好温柔。我不敢靠近你。"

"为什么？"

"因为我怕我会伤害你。我怕我的世界太复杂，会弄脏你的世界。"

"月棠，你没有伤害我。你保护了我。你保护了念念。你给了我们一个家。"

"清歌——"

"月棠，四十年了。我想对你说一句话。"

"什么话？"

"谢谢你。谢谢你出现在我的生命里。谢谢你爱我。谢谢你保护我。谢谢你给了我一个家。谢谢你陪我走过四十年。"

沈月棠的眼眶红了。

"清歌，我也想对你说一句话。"

"什么话？"

"我爱你。四十年前爱你。四十年后依然爱你。永远爱你。"

顾清歌扑进她怀里。

"月棠，我也爱你。永远爱你。"

---

念念和林远带着林月来了。

"月棠妈妈，清歌妈妈，四十年快乐。"

"谢谢念念。"

"月棠妈妈，念念想送你们一份礼物。"

"什么礼物？"

念念拿出一本相册。

"这是念念整理的。从月棠妈妈和清歌妈妈认识的第一天开始，到现在的照片。"

沈月棠翻开相册。

第一张照片，是四十年前拍的。沈月棠和顾清歌站在门口，中间站着五岁的念念。

第二张照片，是念念上小学时拍的。沈月棠和顾清歌站在校门口，牵着念念的手。

第三张照片，是念念上初中时拍的。沈月棠和顾清歌坐在家长席上，看着念念领奖。

第四张照片，是念念上高中时拍的。沈月棠和顾清歌站在校门口，念念穿着校服。

第五张照片，是念念上大学时拍的。沈月棠和顾清歌站在北大门口，念念穿着学士服。

第六张照片，是念念结婚时拍的。沈月棠和顾清歌站在念念身边，念念穿着婚纱。

第七张照片，是林月出生时拍的。沈月棠和顾清歌抱着刚出生的林月。

第八张照片，是林月上小学时拍的。沈月棠和顾清歌站在校门口，牵着林月的手。

第九张照片，是今天拍的。四个人站在院子里，看着月亮。

沈月棠看着相册，眼泪流了下来。

"念念——"

"月棠妈妈，念念想告诉你们。念念的每一步成长，都有月棠妈妈和清歌妈妈。念念的每一个重要时刻，都有你们。念念是世界上最幸福的孩子。因为念念有两个世界上最爱念念的妈妈。"

"念念——"

"月棠妈妈，清歌妈妈，念念爱你们。"

沈月棠抱住念念。

"念念，月棠妈妈也爱你。"

顾清歌也抱住念念。

"念念，清歌妈妈也爱你。"

林月跑过来。

"月月也爱月棠外婆和外婆。"

四个人抱在一起。

月光洒在她们身上。

温柔地见证着这份爱。

四十年的爱。

永远的爱。
