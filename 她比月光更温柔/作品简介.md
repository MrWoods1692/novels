# 作品简介

## 《她比月光更温柔》

**类型**：现代都市 / 百合 / 甜宠 / 治愈

**一句话简介**：
冷面律师遇上温柔画家，她用月光般的温柔，融化了她冰封十年的心。

**详细简介**：

沈月棠，二十九岁，京城最年轻的合伙人级律师，业界人称"铁娘子"。她冷静、理性、不近人情，把所有人都挡在心门之外。没人知道，她心里藏着一道十年前的伤疤——那个在她最黑暗时刻离开的人。

顾晚宁，二十七岁，自由插画师，像月光一样温柔的女子。她独自带着一个五岁的女儿生活，用画笔记录世界的美好。她搬进沈月棠隔壁的那天，命运的齿轮开始转动。

一个是理性至上的律师，一个是感性至上的画家。
一个习惯了独来独往，一个带着孩子努力生活。
一个把心锁在冰层之下，一个用温柔融化一切。

从邻居到朋友，从朋友到心动，从心动到深爱——
当沈月棠终于鼓起勇气打开心门，却发现顾晚宁身上藏着一个秘密，而这个秘密，恰好与她十年前的那道伤疤有关……

"我以为我这辈子不会再爱任何人。"
"那你现在呢？"
"现在……我只想爱你，和你的月光。"
