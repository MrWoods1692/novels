# 第十三章 二十年

结婚二十周年那天，沈屿请了假，说要带林晚星去一个地方。

"又去高中？"林晚星坐在副驾驶上，笑着问。

"不是。"

"那是哪里？"

"到了你就知道了。"

车开了三个小时，最后停在海边的一座小房子前。

白色的墙壁，蓝色的屋顶，门口种着一排向日葵。从窗户望出去，能看到一望无际的大海。

"这是……"

"我买的。"沈屿说，"结婚二十周年礼物。"

林晚星愣住了："你什么时候买的？"

"去年。装修了半年。"

"你一个人弄的？"

"嗯。周末来，平时回去上班。"

"你为什么不告诉我？"

"想给你一个惊喜。"沈屿拉着她的手，推开院子的门，"进来看看。"

院子里有一棵梧桐树，虽然还不大，但已经长出了茂密的叶子。

"海边能种梧桐？"

"查过资料。这个品种可以。"

林晚星走到树下，看到树干上刻着两个字——"同桌"。

"沈屿，这是你刻的？"

"嗯。"

"你什么时候学会刻字的？"

"现学的。练了一个月。"

林晚星摸着那两个歪歪扭扭的字，眼眶红了。

"沈屿，你为什么这么用心？"

"因为是你。"沈屿站在她身后，轻声说，"林晚星，二十年前你问我，以后我们还会是同桌吗。我说，如果你愿意的话，大学也可以。"

"现在我想说——如果你愿意的话，一辈子都可以。"

林晚星转过身，扑进他怀里。

"我愿意。我一直都愿意。"

海风吹过，榕树的叶子沙沙作响，像是在为他们的二十年轻轻鼓掌。

---

晚上，两人坐在海边的露台上，看着满天的星星。

"沈屿，你还记得我们第一次见面吗？"

"记得。你趴在桌上翻课本，腿伸到过道里。"

"你能不能换一句？每次都这句。"

"因为那是真的。"

林晚星笑了，靠在他肩上。

"沈屿，你说我们老了以后会是什么样子？"

"你老了也好看。"

"我问的不是这个。"

"我知道。"沈屿握住她的手，"老了以后，我们还是同桌。坐在海边的房子里，看日出日落。你跟我说晚晚的事，我跟你说书里看到的东西。"

"你会不会还是话那么少？"

"可能。但重要的话，我都会跟你说。"

"什么重要的话？"

沈屿转过头，认真地看着她。

"林晚星，我爱你。"

"从高二到现在，一直爱。"

"到老了，也爱。"

林晚星的眼泪掉下来了。她擦了擦眼泪，笑着说："沈屿，你这个人，怎么二十年了还是这么会说话？"

"不是会说话。"沈屿说，"是真话。"

海浪拍打着礁石，星星在夜空中闪烁。

两个人在秋千上坐了很久很久。

就像二十年前，他们坐在高中教室的座位上一样。

---

第二天早上，林晚星醒来的时候，沈屿已经在厨房做早餐了。

她走到厨房门口，靠在门框上看着他。

晨光从窗户洒进来，落在他身上。他的头发白了一些，眼角有了皱纹，但动作还是和年轻时一样利落。

"醒了？"沈屿头也不回，"再等两分钟，蛋马上好。"

林晚星忽然有一种时空错乱的感觉。

二十年前，他们刚结婚的时候，他也是这样站在厨房里煎蛋，说着同样的话。

"沈屿。"

"嗯？"

"二十年前你也是这么说的。"

沈屿的手顿了一下，然后继续煎蛋："因为二十年来，每天早上都在做同样的事。"

"你不会腻吗？"

"不会。"沈屿把煎蛋盛进盘子里，"因为是给你做的。"

林晚星走过去，从背后抱住他。

"沈屿，下辈子我们还要做同桌。"

"好。"

"下下辈子也要。"

"好。"

"下下下辈子也要。"

"好。"沈屿转过身，把她圈进怀里，"不管多少辈子，我都坐在你旁边。"

林晚星把脸埋在他胸口，笑了。

窗外的榕树在晨风中轻轻摇曳，树干上那两个字——"同桌"——在阳光下闪闪发光。
