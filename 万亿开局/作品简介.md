# 作品简介

## 《万亿开局》

**类型：** 都市 / 商战 / 爽文

**一句话简介：** 重生回到高考那年，绑定万亿神豪系统，林北辰以为自己是来花钱的，却发现每一笔消费都在解锁这个世界的隐藏真相。

**简介：**

林北辰重生了。

回到十八岁那年，高考前三天。

还没来得及感慨人生重来，脑海里就响起一道冰冷的机械音——

"万亿神豪系统已绑定。初始资金：1,000,000,000,000 元。"

"任务：花光它。"

林北辰笑了。花钱？这还不简单？

买豪宅、开跑车、投公司、砸市场……他以为这就是一场挥金如土的爽文剧本。

直到他发现——

这个世界的银行账户里，多出来的不只是钱。

还有他前世从未见过的人、从未发生的事、以及……从未存在过的"规则"。

万亿开局，不是终点，是钥匙。

**标签：** 重生、系统、神豪、悬疑、都市、爽文
