# 作品简介

## 《百美图》

**类型：** 都市 / 系统 / 爽文 / 后宫

**一句话简介：** 绑定"百美图鉴"系统，每收录一位绝世美人的真心，就能获得逆天能力。当一百位女神齐聚身边，且看平凡少年如何登顶世界之巅。

**简介：**

陈默，二十二岁，江城市一名普通的快递员。

没背景、没学历、没钱——标准的"三无青年"。

直到那天，他送快递时意外救下一位被追杀的绝美女子，脑海中响起一道声音——

"百美图鉴系统已激活。检测到第一位图鉴目标：苏清寒，颜值评分98，稀有度SSR。"

"收录奖励：获得能力——过目不忘。"

"当前进度：1/100。"

陈默愣住了。

一百个？他要找一百个绝世美女？

而且每收录一位，就能获得一项逆天能力？

过目不忘、武道宗师、医术通神、商业奇才、预知未来……

当别人还在为一套房奋斗时，他已经坐拥百美，俯瞰众生。

当别人还在996加班时，他已经站在世界之巅，翻手为云覆手为雨。

"我不是花心，我只是在完成系统任务。"

"而且——她们每一个，我都是真心的。"

**标签：** 都市爽文、系统流、后宫、逆袭、商战、武道、甜宠、多女主
